用它能一天干完别人要两周的界面活儿，98570 星的 GitHub 秘籍。

它是个 CSS 框架，但跟传统的不一样。你不用写像 `margin: 10px;` 这种具体样式，而是直接用像 `py-5` 这种带前缀的类名。比如要一个高 5 像素 的上下边距，直接加 `py-5` 就行，它自己会算好样式。这能省下不少写 CSS 的时间，而且样式都写在 HTML 里，改起来更方便。

真实场景假设你要做一个按钮，只需要在 HTML 里加 `bg-blue-500 text-white hover:bg-blue-700` 这几个类名，TailwindCSS 就会自动生成一个背景色是蓝色、文字是白色、鼠标移上去会变深色的按钮，不用你单独写一套 CSS。要是要做响应式设计，只需要再加 `sm:px-10` 这种带屏幕大小前缀的类名，它就能在不同屏幕尺寸下自动调整布局。
怎么做到的TailwindCSS 的核心是预定义了很多种类的类名，比如颜色、间距、字体大小、边框等等。你只需要在 HTML 里把对应的类名加上去，它就会根据配置文件自动生成对应的 CSS。它的配置文件还可以自己修改，比如你想把所有按钮的蓝色改成绿色，只需要改配置文件里的一行就行，所有按钮都会自动变绿。
