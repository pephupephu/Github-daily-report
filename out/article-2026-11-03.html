01 agent-desktop Rust · 10,943 star · 今日 +2275

agent-desktop 今天单日 +2275 star。

这是一个为 AI 代理设计的跨平台桌面自动化 CLI 工具，通过操作系统的可访问性树来读取和操作应用。它提供快照、点击、输入等 60+ 个命令，输出 JSON 格式的操作对象引用，让 AI 代理能像人类一样“看”和“点”桌面。

放进一个真实场景：AI Agent 桌面自动化：让 AI 代理自动处理网页表单、文件管理等任务。

它是怎么做到的：基于可访问性树：利用 macOS/Windows 的 UI 自动化 API 或 Linux 的 AT-SPI 协议，而非像素匹配。；Ref 机制：快照生成唯一 ID（Ref），代理操作 Ref 并再次快照验证，UI 变化需重新快照。；进程隔离：每个 CLI 命令独立进程运行，默认无头模式不抢占焦点，避免干扰用户。；JSON 协议：结构化输出，包含错误码、建议和重试策略，便于 Agent 解析。；FFI 绑定：提供 C 语言接口库，支持进程内调用，降低频繁启动进程的性能损耗。；JEV Helper：可选的隐私助手，将屏幕描述发送给模型而不暴露原始截图。
