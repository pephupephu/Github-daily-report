# 安全审计

一种编码代理技能，可将您的代理变成安全审核员。它通过侦察、覆盖主导的搜寻、候选人验证、结构化输出、独立记录验证和目标中立报告来协调孤立的代理。

这是为 Cloudflare 的漏洞发现工具奠定了基础的技能，如[构建您自己的漏洞工具](https://blog.cloudflare.com/build-your-own-vulnerability-harness)中所述。该安全带发展成为一个多级、覆盖整个车队的系统；这个技能是它演变而来的single-repo起点。

## 它的作用

该技能分六个阶段进行结构化审核：

1. **侦察**——在“architecture.md”和“coverage-ledger.json”中映射架构、信任边界、输入表面、先验证据和确定性覆盖。
2. **覆盖范围主导的狩猎**——从账本单元中分配孤立的猎人，记录他们的检查，并使用覆盖范围批评家来寻找差距。
3. **候选验证**——将每个独特的候选提供给试图反驳它的新验证者。
4. **结构化输出** -- 将 `confirmed`、`needs_validation` 和 `rejected` 记录写入 `findings.json` 并根据 `report-schema.json` 验证它们。
5. **独立记录验证**——新代理验证最终来源声明。材料替换品将接受另一位独立验证者。

6. **目标中立报告** -- 从已验证的记录和覆盖分类账中派生出“REPORT.md”、“FINDINGS-DETAIL.md”和“NEEDS-VALIDATION.md”。

父级在创建分类帐后以及每次更新分类帐后运行“validate-coverage-ledger.cjs”。它在第 4 阶段运行“validate-findings.cjs”，并在每次第 5 阶段替换后再次运行。

判决是不同的：“已确认”具有完整的源跟踪和有限的观察结果，“需要验证”具有确切的未解决事实且没有严重性，而“已拒绝”记录了被反驳的候选人。

针对同一存储库的多次运行是累加的。该技能使用先前的分类账和发现来定位差距，重新验证更改的源，并继续当前源证据，而不将陈旧或未解决的工作视为所涵盖的。

## 关于

vLLM 是一个快速且易于使用的 LLM 推理和服务库。

vLLM 最初由加州大学伯克利分校的 [Sky 计算实验室](https://sky.cs.berkeley.edu) 开发，现已发展成为最活跃的开源 AI 项目之一，由数十个学术机构和公司组成的多元化社区、超过 2000 名贡献者构建和维护。

vLLM 的速度很快：

- 最先进的服务吞吐量
- 使用 [**PagedAttention**](https://blog.vllm.ai/2023/06/20/vllm.html) 有效管理注意力键和值内存
- 连续批处理传入请求、分块预填充、前缀缓存
- 通过分段和完整的 CUDA/HIP 图快速灵活地执行模型
- 量化：FP8、MXFP8/MXFP4、NVFP4、INT8、INT4、GPTQ/AWQ、GGUF、压缩张量、ModelOpt、TorchAO 和 [更多](https://docs.vllm.ai/en/latest/features/quantization/index.html)
- 优化的注意力内核，包括 FlashAttention、FlashInfer、TRTLLM-GEN、FlashMLA 和 Triton
- 使用 CUTLASS、TRTLLM-GEN、CuTeDSL 优化 GEMM/MoE 内核以实现各种精度
- 推测解码，包括 n-gram、后缀、EAGLE、DFlash

- 使用 torch.compile 自动生成内核和图形级转换
- 分类预填充、解码和编码

vLLM 灵活且易于使用：

- 与流行的Hugging Face模型无缝集成
- 使用各种解码算法提供高吞吐量服务，包括*并行采样*、*波束搜索*等
- 用于分布式推理的张量、管道、数据、专家和上下文并行性
- 流媒体输出
- 使用 xgrammar 或指导生成结构化输出
- 工具调用和推理解析器
- OpenAI 兼容的 API 服务器，以及 Anthropic Messages API 和 gRPC 支持
- 对密集层和 MoE 层的高效多 LoRA 支持
- 支持 NVIDIA GPU、AMD GPU、Intel GPU 和 x86/ARM/PowerPC CPU。此外，还有多种硬件插件，如 Google TPU、Intel Gaudi、IBM Spyre、华为 Ascend、Rebellions NPU、Apple Silicon、MetaX GPU 等。

vLLM 无缝支持 Hugging Face 上的 200 多个模型架构，包括：

- 仅解码器法学硕士（例如 Llama、Qwen、Gemma）
- 专家混合法学硕士（例如 Mixtral、DeepSeek-V3、Qwen-MoE、GPT-OSS）
- 混合注意力和状态空间模型（例如，Mamba、Qwen3.5）
- 多模态模型（例如 LLaVA、Qwen-VL、Pixtral）
- 嵌入和检索模型（例如，E5-Mistral、GTE、ColBERT）
- 奖励和分类模型（例如 Qwen-Math）

在[此处](https://docs.vllm.ai/en/latest/models/supported_models.html)查找受支持模型的完整列表。
