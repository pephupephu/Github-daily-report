**它到底是什么**：agent-browser 是一个用 Rust 编写的原生命令行工具，用于自动化浏览器操作，它可以让 AI 代理逐条命令控制浏览器，通过 `snapshot` 命令获取页面的紧凑文本表示，并使用引用（如 `@e1`）来标识每个元素，AI 代理可以根据引用操作页面，然后重新读取页面检查结果，浏览器在每次命令之间保持打开状态，因此每个步骤都可以通过一条简短的 shell 命令完成。

**核心机制**：
- 使用 Chrome DevTools Protocol 控制浏览器
- 通过命令行接口与后台守护进程交互
- 提供页面快照功能，将页面转换为可操作的引用
- 支持多种选择器，如 CSS 选择器、XPath 和语义定位器
- 内置多种技能，如核心循环、等待和常见工作流
- 支持多种浏览器引擎和云浏览器提供商
- 提供会话持久化功能
- 支持多种调试和性能分析工具

**使用场景**：
- AI 代理需要自动化浏览器操作的场景，如网页数据抓取、自动化测试等
- 需要与网页进行交互的场景，如填写表单、点击按钮等
- 需要监控网页变化并进行响应的场景
- 需要在不同浏览器引擎和云浏览器提供商之间切换的场景

**需要注意的坑**：
- 需要安装 Chrome for Testing 浏览器，可能需要额外配置
- 某些操作可能因为页面元素状态问题而失败，需要重新获取页面快照后重试
- 会话持久化功能需要额外配置，否则浏览器会在一段时间后关闭

## 7. prometheus/prometheus

**67,496⭐ · 今日 +322 · Go** · 创建于 2012-11-24 · [仓库](https://github.com/prometheus/prometheus)

**它到底是什么**：Prometheus 是一个开源的监控系统和时间序列数据库，它通过 HTTP 拉取模型从配置的目标收集指标数据，使用 PromQL 查询语言进行数据分析，并能根据规则表达式触发警报。用户可以通过配置文件定义监控目标、规则和警报条件，并通过 Web 界面查看监控数据和图表。

**核心机制**：
- 多维度数据模型：使用指标名称和键值对维度定义时间序列
- PromQL 查询语言：支持对多维数据进行灵活查询和分析
- HTTP 拉取模型：主动从配置的目标拉取指标数据
- 服务发现机制：支持静态配置和服务发现插件自动发现目标
- 规则表达式：支持基于指标数据触发警报和创建衍生指标
- 单节点自主运行：单个服务器节点可以独立运行，无需分布式存储
- 推送门关：支持批量任务通过中间件推送指标数据
- 联邦机制：支持多 Prometheus 实例的层级和横向联邦

**使用场景**：
- 云原生环境下的系统和服务监控
- Kubernetes 等容器化平台的监控和告警
- 微服务架构下的分布式系统监控
- 需要实时数据分析和告警的场景

**需要注意的坑**：
- Prometheus 不适合作为库使用，官方不提供库级别的支持
- 服务发现机制可能存在配置复杂和性能瓶颈的问题
- 规则表达式和 PromQL 的学习曲线较陡峭
- 大规模部署时需要考虑资源消耗和性能优化
