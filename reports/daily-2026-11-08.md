## 1. vercel-labs/agent-browser

**46,932⭐ · 今日 +190 · Rust** · 创建于 2026-01-11 · [仓库](https://github.com/vercel-labs/agent-browser)

**它到底是什么**：agent-browser 是一个用 Rust 编写的本地 CLI 工具，用于浏览器自动化，允许 AI 代理逐条命令控制浏览器。它可以打开网页，将页面作为可访问性树读取，并通过 shell 对元素进行操作。通过 `snapshot` 命令返回页面的紧凑文本形式，每个元素都有一个引用（如 `@e1`），代理可以根据引用操作元素，然后重新读取页面检查结果，浏览器在命令之间保持打开状态，因此每个步骤都是一条简短的 shell 调用。

**核心机制**：
- 使用 Chrome DevTools Protocol 控制浏览器
- 通过 Rust 编写的本地 CLI 发送命令到后台守护进程
- 支持多种浏览器引擎，包括 Chrome for Testing、Lightpanda、Obscura 和 Mobile Safari
- 提供页面快照功能，将页面元素转换为可引用的格式
- 支持 CSS 选择器、XPath 和语义定位器进行元素查找
- 内置多种技能，如核心循环、等待和常见工作流
- 支持会话持久化，可以在一段时间内保持浏览器状态

**使用场景**：
- AI 代理需要自动化浏览器任务，如网页抓取、表单填写和交互
- 需要将浏览器自动化集成到现有的 AI 工作流中
- 开发需要与网页进行交互的智能应用
- 测试和调试需要自动化浏览器行为的场景

**需要注意的坑**：
- 需要安装 Chrome for Testing 或其他浏览器引擎，可能需要额外的硬件资源
- 某些操作可能因浏览器行为或页面复杂性而失败，需要重试或调整策略
- 需要定期更新技能和 CLI 以保持兼容性和功能完整性
