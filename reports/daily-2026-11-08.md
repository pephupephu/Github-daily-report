## 1. vercel-labs/agent-browser

**47,144⭐ · 今日 +190 · Rust** · 创建于 2026-01-11 · [仓库](https://github.com/vercel-labs/agent-browser)

**它到底是什么**：agent-browser 是一个用 Rust 编写的原生命令行工具，用于浏览器自动化，它允许 AI 代理逐条命令控制浏览器，可以打开网页、将页面作为可访问性树读取，并从 shell 中对元素进行操作。通过 `snapshot` 命令获取页面的紧凑文本表示，每个元素都有一个引用（如 `@e1`），AI 代理可以根据引用执行操作，然后重新读取页面以检查结果，浏览器在命令之间保持打开状态，因此每个步骤都是一条简短的 shell 调用。

**核心机制**：
- 使用 Chrome DevTools Protocol 控制浏览器
- 通过命令行接口与后台守护进程通信
- 支持多种浏览器引擎，包括 Chrome for Testing、Lightpanda、Obscura 和 Mobile Safari
- 提供页面快照功能，将页面元素转换为可引用的格式
- 支持 CSS 选择器、XPath 和语义定位器进行元素查找
- 内置多种技能，如核心循环、等待和常见工作流
- 支持会话持久化，可以在一段时间内保持浏览器状态

**使用场景**：
- AI 代理需要自动化浏览器操作的场景，如网页数据抓取、自动化测试、网页交互等
- 需要将浏览器自动化集成到现有 AI 系统中的开发者
- 需要进行网页内容分析和处理的科研人员

**需要注意的坑**：
- 需要安装 Chrome for Testing 或其他浏览器引擎，可能需要额外的系统依赖
- 元素引用在页面变化后失效，需要重新获取快照
- 某些情况下，如元素被遮挡或不可见时，操作可能失败
