## 12. NVIDIA/SkillEvaluator

**它到底是什么**：SkillEvaluator 是一个用于评估 AI 代理技能的多层框架，通过质量门禁、语义重叠检测、合成评估数据集生成和实时代理评估来衡量技能对代理行为的影响。它支持从命令行直接运行、集成到 CI/CD 流程中或连接到代理系统，通过三个层级（验证、去重和实时评估）来全面检查技能的质量和效果。

**核心机制**：
- Agent Skills 规范定义技能结构，包含指令和辅助文件
- Tier 1 静态验证检查技能的安全性、格式和兼容性，使用 SkillSpector 和 Gitleaks 进行安全扫描
- Tier 2 去重检测技能间的指导重复或语义重叠，通过嵌入和聊天数据进行比较
- Tier 3 实时评估测量技能对代理任务结果的实际影响，使用 LLM 或支持代理的沙箱环境
- 质量门禁机制在 Tier 1 失败时阻止后续层级执行，可配置通过阈值
- 合成数据集生成支持无 LLM 的质量检查和有 LLM 的评估反馈
- 支持多种 LLM 提供商（如 NVIDIA Build）和代理系统集成，需配置 API 密钥和模型客户端

**使用场景**：
- AI 研发团队用于评估和优化自定义技能的质量和效果
- 企业级应用在集成 AI 代理前进行技能安全性和有效性审查
- 开源社区和开发者用于自动化技能验证流程，提升代理系统的可靠性
- 教育机构用于教学实验，展示 AI 技能评估方法

**需要注意的坑**：
- Tier 3 实时评估需要 NVIDIA Build API 密钥或代理环境，可能产生额外费用
- 依赖外部扫描工具（SkillSpector、Gitleaks）和 LLM 提供商，需额外配置和许可管理
- 无 LLM 的质量检查无法完全替代实时评估，可能遗漏动态行为问题
