## 它真的有效吗？

我是一名受过训练的地球物理学家。当我的职位在 2025 年底被裁掉时，我构建了这个框架来运行我自己的求职 - 与此存储库中相同的“/scrape”、“/apply”和“/interview”工作流程，在我自己的职业生涯中每周使用。我对每一位与我交谈过的雇主都坦率地表达了这一点，这通常会引发真正的技术对话，而不是对我不利。

69 份量身定制的申请，20 次第一次面试，最后签订了一份合同，我于 2026 年 6 月开始担任人工智能工程师。人们一直在问这是否真的有效。它让我被录用了。现在它是你的了。

*较长的版本，包括完整的申请渠道，位于 [LinkedIn](https://www.linkedin.com/in/mads-lorentzen/)。*

 这是否为您节省了周日写求职信的时间？考虑一杯咖啡。
 它让你找到了工作吗？也许是两个。 ☕

 
 
 

## 这是什么

结构化工作流程，将 Claude Code 转变为全栈职位申请助手。核心工作流程（自我分析、适合性评估和起草者-审阅者申请流程）**与语言和国家/地区无关**。职位门户搜索技能是为丹麦市场构建的（Jobindex、Jobnet、Akademikernes Jobbank 等），但该模式旨在替换为您当地的职位委员会。

````
/设置/刮擦/应用 

 维维维
填写 搜索职位 评估适合度
您的个人资料门户评分和推荐

 维维维
个人资料当前匹配简历草案+求职信
准备好适合度等级的文件（LaTeX，定制）

 伏
 选择匹配 审稿人评论
 -> /应用 -> 修改 -> 最终输出
````

该框架编码了职业指导最佳实践，包括结构化评估标准、前瞻性求职信框架和可选的薪资基准。

-Python 3.10+
- [Bun](https://bun.sh)（用于求职 CLI 工具）
- 使用 `lualatex` 和 `xelatex` 的 LaTeX 发行版：[TeX Live](https://tug.org/texlive/)、[MacTeX](https://tug.org/mactex/)、[TinyTeX](https://yihui.org/tinytex/) 或 [MiKTeX](https://miktex.org/)。 CV 使用“lualatex”进行编译（pdflatex 在现代 MiKTeX 安装上经常失败，并出现“fontawesome5”字体扩展错误）；求职信使用“xelatex”进行编译，因为“cover.cls”需要“fontspec”。如果使用最小 TeX 安装（例如 TinyTeX 或 BasicTeX），请安装 [SETUP.md](SETUP.md#minimal-tex-install-tinytexbasictex) 中列出的额外软件包。
- 可选：“pip install pypdf”用于“/apply”的 ATS 可解析性检查（BSD；不需要 Poppler）。 Poppler `pdftotext` 仍然是后备方案（macOS：`brew install poppler`，Debian/Ubuntu：`apt install poppler-utils`，Windows：`choco install poppler`）。如果两者都缺失，检查将降级为视觉关键字审核。

“/setup”提供三种路径：如果您已填充一个“documents/”文件夹（简历 PDF、LinkedIn 导出、文凭、推荐信、过去的申请），请阅读您的“documents/”文件夹，导入粘贴在聊天中的一份简历，或者进行面试。它会自动检测您拥有的内容并询问。文档文件夹模式是幂等的，并且当您添加更多材料时可以安全地重新运行；有关布局，请参阅“documents/README.md”。

1. **[ComfyUI 核心](https://github.com/comfyanonymous/ComfyUI)**
 - 大约每两周发布一个新的主要稳定版本（例如 v0.7.0）。

- 在向后移植没有意义的情况下，补丁版本仍可用于主分支上的发布。
 - 稳定版本标签之外的提交可能非常不稳定并会破坏许多自定义节点。
 - 作为桌面版本的基础

2. **[舒适桌面](https://github.com/Comfy-Org/Comfy-Desktop)**
 - 使用最新的稳定核心版本构建新版本

3. **[ComfyUI 前端](https://github.com/Comfy-Org/ComfyUI_frontend)**
 - 每两周以上前端更新就会合并到核心存储库中
 - 即将发布的核心版本的功能被冻结
 - 下一个发布周期的开发仍在继续
